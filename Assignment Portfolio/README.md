# PORTFOLIO WEBSITE - ASSIGNMENT 1 & 2

Folder: Assignment Portfolio

## ASSIGNMENT 1 - PORTFOLIO WEBSITE

### Files:

* index.html              Main HTML portfolio page
* images/boss.webp        Local boss image used in the portfolio
* screenshots/            Screenshots of the completed webpage

### Requirements Completed:

* Boss's name and position displayed.
* Navigation links to different sections of the portfolio.
* Introduction section with formatted text.
* Boss image with a caption.
* Experience displayed using an ordered list.
* Skills displayed using a table.
* Projects displayed using an unordered list.
* YouTube video embedded in the webpage.
* Contact form with name, email, phone number, gender, and role.

### How to Open:

1. Open `index.html` in any modern web browser.
2. Use the navigation links to jump to Introduction, Experience, Skills, Projects, YouTube Video, and Contact.

### Note:

The YouTube video is embedded from YouTube and requires an internet connection when viewing the page.

## ASSIGNMENT 2 - STYLING THE PORTFOLIO USING CSS

### Files:

* index.html              Updated HTML portfolio page
* style.css               CSS stylesheet for the portfolio
* images/boss.webp        Local boss image used in the portfolio
* screenshots/            Screenshots of the completed webpage

### Requirements Completed:

* Name centered at the top.
* Position displayed below the name.
* Navigation links displayed in a horizontal row.
* Navigation links have no text decoration.
* Header has a different background color from the body.
* Introduction heading is displayed on the left and in bold.
* Introduction paragraph is justified.
* Image is centered with a caption and rounded edges.
* Experience items use alternating light and bold font weights.
* Skills table is styled with colors, borders, and spacing.
* Projects section is styled with padding and rounded edges.
* YouTube video is centered and properly sized.
* Contact form is styled with name, email, phone number, gender, and role fields.
* Website is responsive for different screen sizes.

### CSS Concepts Used:

* CSS variables
* Element selectors
* ID selectors
* Child selectors
* Attribute selectors
* `:hover`
* `:focus`
* `:nth-child()`
* Colors and background colors
* Margin and padding
* Borders
* Border radius
* Width and height
* Media queries

### How to Open:

1. Open `index.html` in any modern web browser.
2. Make sure `style.css` is in the same `Assignment Portfolio` folder.
3. Use the navigation links to move between the sections.

### Note:

The YouTube video requires an internet connection when viewing the page.
